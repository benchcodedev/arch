# Architera Studio

> Architecture for Inspired Living — Contemporary Architecture & Spatial Design Practice

Architera Studio is a high-performance, responsive editorial architecture website faithfully matching modern architectural design standards, featuring fluid staggered entrances, interactive tabbed services with infinite horizontal marquee tickers, an asymmetrical bento grid portfolio, and a smooth auto-advancing testimonials carousel.

---

## 🌟 Key Features

1. **Editorial Hero Section**:
   - 4 vertical staggered strips featuring bespoke residential projects.
   - Distinctive typography with architectural drafting grid backdrop.
   - Interactive bottom-right Studio badge trigger and interactive strip hotspots.

2. **Empowering Your Architecture Journey**:
   - 3-column asymmetric bento layout (Hillside villa + Explore CTA, featured pool villa, dusk residence).
   - Staggered scroll-triggered entrance motion.

3. **Interactive Services Tabbed Showcase**:
   - 4 interactive disciplines: *Architecture*, *Interior*, *Renovation*, and *Construction*.
   - Active state features a top white badge with an **infinite horizontal running marquee ticker**.
   - Smooth dark backdrop overlay and sliding *Learn More ↗* action.
   - Full touch & hover support across mobile, tablet, and desktop viewports.

4. **Curated Projects Bento Grid**:
   - Section header with title and editorial design narrative.
   - **Row 1**: *Cascade Villa* and *InHabit Spaces*.
   - **Row 2**: Asymmetrical 4-column composition with architectural negative space (*UrbanLift*, empty space, *Renew Works*, *Canvas & Co*).
   - **Row 3**: Asymmetric cards featuring *Lumière Living* and *Cornerstone Campus*.
   - Interactive project detail modal previews.

5. **Testimonials Slider**:
   - Horizontal sliding carousel track with centered active card and side peeking cards.
   - Smooth auto-play with 3.5s interval and pause-on-hover/touch.
   - Verified authentic client reviews and portrait avatars.

6. **News and Blog**:
   - 3-column editorial articles with smooth hover scaling and interactive links.

7. **"Let's Talk" Footer**:
   - Pitch-black (`#000000`) minimal luxury design.
   - Rounded pill consultation CTA, 4-column navigation, and social links.

8. **Slide-over Drawers & Modals**:
   - Mobile navigation drawer for seamless smartphone access.
   - Slide-over shopping bag drawer.
   - Interactive contact consultation modal.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it with any local static HTTP server:

```bash
# Using Python
python -m http.server 8080

# Using Node.js
npx serve .
```

---

## 🛠️ Built With

- **HTML5**: Semantic markup & accessible structure.
- **Tailwind CSS**: Utility-first styling with custom extended theme.
- **Custom CSS (`css/style.css`)**: Hardware-accelerated keyframe animations, marquee tickers, and responsive layouts.
- **Vanilla JavaScript (`js/main.js`)**: IntersectionObserver scroll reveals, testimonial slider calculations, tab switching, and modal controls.
- **Google Fonts**: *Plus Jakarta Sans* & *Inter*.
